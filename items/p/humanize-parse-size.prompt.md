Add `humanize.parse_naturalsize(value)`, the inverse of `humanize.naturalsize()`: it turns a human-readable size into a number of bytes.

Put it in `src/humanize/filesize.py`, export it from the `humanize` package, and add it to `humanize.__all__`.

Behaviour:
- `value` must be a `str`. Anything else (including `bytes`, `int`, `float`, `Decimal`, `None`) raises `TypeError`.
- Accepted form, in this order: optional leading whitespace; an optional sign `+` or `-`, immediately followed by the number; the number, which is either digits with an optional fractional part (`12`, `12.5`, `007`) or a dot followed by digits (`.5`); optional whitespace; an optional unit; optional trailing whitespace. "Whitespace" means any characters for which `str.isspace()` is true (spaces, tabs, newlines). No exponent (`1e3`), no thousands separators (`1,000`, `1 000`), no trailing dot (`1.`), no hexadecimal, no `inf`/`nan`. Anything that does not match raises `ValueError`.
- Units are matched case-insensitively:
  - no unit, `B`, `Byte`, `Bytes`: bytes (x1). A lowercase `b` also means bytes.
  - decimal `kB`, `MB`, `GB`, `TB`, `PB`, `EB`, `ZB`, `YB`, `RB`, `QB`: x1000 to the power 1 to 10;
  - binary `KiB`, `MiB`, `GiB`, `TiB`, `PiB`, `EiB`, `ZiB`, `YiB`, `RiB`, `QiB`: x1024 to the power 1 to 10;
  - GNU single letters `K`, `M`, `G`, `T`, `P`, `E`, `Z`, `Y`, `R`, `Q`: x1024 to the power 1 to 10 (the base `naturalsize(..., gnu=True)` uses).
  Any other unit raises `ValueError`.
- The result is an `int`: the number times the multiplier, computed exactly, with no loss of digits however large the multiplier (`"1.1 QB"` is exactly `11 * 10**29`; `"1.0Q"` is exactly `1024**10`), then rounded to the nearest integer, with halves rounded away from zero (`"2.5 B"` -> 3, `"-0.5"` -> -1, `"2.9K"` -> 2970). `"-0"` gives 0.
- Every string that `naturalsize()` produces in its default, `binary=True` and `gnu=True` modes therefore parses back, for example `"300 Bytes"` -> 300, `"1 Byte"` -> 1, `"3.0 MB"` -> 3000000, `"2.9 KiB"` -> 2970, `"300B"` -> 300, `"-4.0 KiB"` -> -4096.

Document the function with a docstring in the style of the module.
